# `reference/68k/`

68000-era material. **Reading, not a build input** — nothing in this repository targets a
68000, and no document cites these files.

| File | What |
|---|---|
| `Mac-Plus.ROM` | Macintosh Plus ROM image |
| `102658076_quickdraw_acc.zip` | Apple **QuickDraw** source, released by the Computer History Museum (catalogue no. 102658076) |
| `102658076_macpaint_acc.zip` | Apple **MacPaint** source, same CHM release |

QuickDraw is here for the same reason `docs/coco3_c64.md` is: it is the best-documented
worked example of getting a lot of graphics out of very little hardware, and
`video/docs/graphics.md`'s span writer solves a related problem in TTL.

These are tracked in git — unlike the scans elsewhere under `reference/` — because they
are small. They are **not** covered by this project's licensing; the CHM releases carry
Apple's own terms.
